First time here?
The intranet is a set of doors into one shared record. Start with the shelf to see what binds you, the calendar to show up, and the board to find work and play. The map on the left carries everything else.
One record, many doors. Everything here reads and writes one shared record, so what you see is what the cooperative knows. Nothing is kept twice and nothing is quietly overwritten. Words that carry weight are defined in the Lexicon.
